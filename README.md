# Datheon Python Programming Internship

A collection of five Python projects completed as part of the **Datheon Python Programming Internship**, focused on Python fundamentals, problem-solving, automation, file handling, and Object-Oriented Programming (OOP).

## About the Internship

The Datheon Python Programming Internship is a hands-on, four-week program designed to develop practical Python programming skills through real-world assignments.

During this internship, I worked on five projects involving interactive games, investment portfolio tracking, filesystem automation, rule-based chatbot development, and an object-oriented inventory management system.

## Projects Completed

### Task 1 – Hangman Word Guessing Game

A terminal-based word guessing game in which the player attempts to identify a randomly selected hidden word within a limited number of attempts.

**Key Features:**
- Random word selection
- Letter-by-letter guessing
- ASCII hangman visualisation
- Tracking previously guessed letters
- Prevention of duplicate guesses
- Victory and defeat messages

**Concepts:** Python fundamentals, strings, loops, conditional statements, sets, and the `random` module.

**Folder:** `Task_1_Hangman`

### Task 2 – Investment Portfolio Tracker

A Python-based investment portfolio tracking utility that calculates investment performance using stock prices, purchase prices, and share quantities.

**Key Features:**
- Enter stock ticker symbols
- Store investment details
- Calculate invested capital and portfolio value
- Calculate percentage gain or loss
- Export portfolio summaries to CSV

**Concepts:** Dictionaries, calculations, CSV handling, file operations, and data management.

**Folder:** `Task 2 – Investment Portfolio Tracker (Python)`

### Task 3 – Automated File Organizer

A Python automation utility that organizes files into appropriate folders based on their file extensions.

**Key Features:**
- Automatic file categorization
- Dynamic folder creation
- File movement using Python libraries
- Handling naming collisions and permission errors
- Logging and execution summary

**Concepts:** `os`, `shutil`, `pathlib`, exception handling, and filesystem automation.

**Folder:** `Task 3 – Automated File Organizer`

### Task 4 – Rule-Based Interactive Terminal Assistant / Chatbot

An interactive terminal chatbot that responds to user queries using predefined rules, keywords, regular expressions, and FAQ-based responses.

**Key Features:**
- Greeting recognition
- Keyword and pattern matching
- FAQ-based responses
- Business information queries
- Fallback responses
- Exit commands such as `bye`, `exit`, and `quit`

**Concepts:** Python functions, dictionaries, JSON, regular expressions, string processing, and conditional logic.

**Folder:** `Task 4: Rule-Based Interactive Terminal Assistant`

### Task 5 – OOPs Architecture: Enterprise Smart Inventory & Asset System

A modular, object-oriented inventory management system designed to manage different types of items, including books, magazines, and digital media.

**Key Features:**
- Add and display inventory items
- Search items using unique IDs
- Checkout and return functionality
- Item-specific fee calculation
- Inventory tracking
- Audit report generation
- Input validation and error handling

**OOP Concepts:**
- Classes and objects
- Abstraction using `ABC` and `@abstractmethod`
- Inheritance
- Encapsulation
- Polymorphism and method overriding
- Properties and setters
- Dunder methods: `__str__`, `__repr__`, `__eq__`, and `__len__`

**Technologies:** Python, `abc`, `datetime`, and object-oriented programming.

**Folder:** `Task_5_Inventory_System`

## How to Run the Projects

### 1. Clone the Repository

```bash
git clone https://github.com/radhikajejurkar453-debug/Datheon_Python_Programming_Internship.git
```

### 2. Navigate to the Repository

```bash
cd Datheon_Python_Programming_Internship
```

### 3. Run an Individual Project

Navigate to the required task folder and execute its Python file.

Example:

```bash
cd Task_1_Hangman
python hangman.py
```

For Task 5:

```bash
cd Task_5_Inventory_System
python main.py
```

Make sure Python 3 is installed on your system.
